# Contributing

1. Open an issue describing the reference algorithm or exercise.
2. Use the standard library and credit any sources or contributors. Include only material you have permission to share.
3. Document input constraints, output contract, complexity, and assumptions.
4. Add deterministic tests covering empty inputs, duplicates, boundaries, and negative values when applicable.
5. Run the suite locally on a maintained Python version and check all CI jobs. [Test instructions](README.md#run-tests)
6. Submit a focused pull request. For your own LeetCode practice, link to the problem and explain your own work. Follow each contest's publication rules.
