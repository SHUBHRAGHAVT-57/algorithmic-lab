# Contributing

1. Open an issue describing the algorithm or exercise.
2. Submit original Python 3 solutions only.
3. Document input constraints, output contract, complexity, and assumptions.
4. Add deterministic tests covering empty inputs, duplicates, boundaries, and negative values when applicable.
5. Run the Python test suite locally and ensure CI passes.
6. Submit a focused pull request; never include contest submissions during an active contest where sharing is prohibited.
